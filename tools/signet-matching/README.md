# השוואת קטלוג ל.כ מול קטלוג פלד / סיגנט

כלי שמתאים בין פריטי קטלוג ל.כ לפריטים המקבילים בקטלוג פלד (SIGNET, KENDO ועוד),
לפי סוג מוצר, מידות, דרייב, עומק, מספר צלעות וסוג ראש.

## הרצה
```
pip install -r requirements.txt
python run.py            # משתמש בעמודי הקטלוג השמורים ב-work/
python run.py --fetch    # מוריד קודם את עמודי הקטלוג מהאתר (כ-1-2 דקות)
python run.py --fetch --refresh   # מוריד מחדש הכל (למשל אחרי עדכון באתר)
```
- קלט: `input/lk_catalog.xlsx` – ייצוא קטלוג ל.כ (עמודות: פריט, שם פריט, מחלקה, שם מחלקה, קבוצה, שם קבוצה, קבוצת משנה, שם קבוצת משנה, מותג לאתר, שם מותג לאתר).
- כתובת הקטלוג: משתנה הסביבה `CATALOG_URL` (ברירת מחדל `https://peledtech.com/catalog2024-25/`).
- פלט: `output/השוואת_קטלוג_לכ_סיגנט_<תאריך>.xlsx` עם 4 גיליונות: סיכום והסבר, התאמות, ל.כ ללא התאמה, סיגנט ללא התאמה.
- התיקיות `input/`, `work/`, `output/` לא נשמרות ב-Git (נתוני חברה וקבצים זמניים).

## איך זה עובד
| קובץ | תפקיד |
|---|---|
| `src/fetch.py` | מוריד את עמודי ה-FlippingBook, שולף את שכבת הטקסט של כל עמוד ואת אינדקס המק"טים שבסוף הקטלוג |
| `src/pilot.py`, `src/lk.py`, `src/match.py` | התאמה מדויקת לבוקסות 1/4"–1/2" ומפתחות רינג פתוח / רצ'ט (עמודים מוגדרים ידנית – ספציפי לקטלוג 2024/25) |
| `src/sigall.py` | בונה רשומה לכל מק"ט בקטלוג: מטבלת מידות או מטקסט חופשי בעמוד |
| `src/cats.py` | מילון קטגוריות: ביטוי לזיהוי בשם פריט ל.כ ובכותרת עמוד אצל פלד |
| `src/feats.py` | חילוץ מאפיינים מטקסט: מ"מ, אינץ', דרייב, T/PH/PZ, מספר יחידות, אורך, עמוק, 12 צלעות, VDE |
| `src/engine.py` | מסווג את מק"טי פלד לקטגוריות ומחשב מאפיינים |
| `src/match_all.py` | מנוע ההתאמה הכללי + רמות ביטחון |
| `src/build_all.py` | בונה את קובץ ה-Excel (תוצאות הפיילוט גוברות על המנוע הכללי) |

## רמות ביטחון
- **ודאי** – אותה קטגוריה, כל המידות והמאפיינים תואמים, מטבלת מידות, מועמד יחיד, רק בקטגוריות מובנות (בוקסות, מפתחות, אלן, ביטים, מקדחים).
- **סביר** – מידה וקטגוריה תואמות אבל פרט אחד לא מאומת.
- **לבדיקה** – התאמה חלקית / לפי מילים / מעמוד עם פריטים רבים.

## כשיוצא קטלוג פלד חדש
1. להריץ `python run.py --fetch` עם `CATALOG_URL` החדש.
2. לבדוק שמספר המק"טים באינדקס סביר.
3. `src/pilot.py` (מילון SPEC) ותיקוני טעויות הדפוס בו מבוססים על מספרי עמודים של 2024/25 – לעדכן או לנטרל.
