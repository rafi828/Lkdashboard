# הוראות ל-Claude Code – הוספת מודול "השוואת מתחרים – סיגנט" ל-Lkdashboard

הקובץ הזה הוכן ב-claude.ai אחרי שבנינו והרצנו את כלי ההשוואה. רפי לא מפתח: כל ההסברים אליו בעברית, צעד-אחר-צעד ובשפה לא טכנית. את פעולות Git (add / commit / push) אתה מבצע בעצמו – רפי לא צריך להעתיק קבצים ידנית.

## שלב 1 – הכנסת הכלי לריפו
1. חלץ את ה-ZIP שרפי מסר לך כך שהתיקייה `tools/signet-matching/` תשב בשורש הריפו (לצד `pages/` וכו').
2. ודא ש-`tools/signet-matching/.gitignore` מונע העלאה של `input/`, `work/`, `output/`, `.venv/` – בהם קטלוג החברה וקבצים זמניים. **אל תעלה אותם ל-GitHub.**
3. ודא שהוספת תיקיית פייתון לא משפיעה על ה-build ב-Railway: `requirements.txt` נמצא בתת-תיקייה ולא בשורש. בדוק אם יש בריפו `railway.json` / `nixpacks.toml` / `.dockerignore` שצריך לעדכן, ואם כן – הסבר לרפי לפני שינוי.
4. צור סביבה וירטואלית בתוך התיקייה (`python -m venv .venv`), התקן `pip install -r requirements.txt`, והרץ `python run.py`.
5. ודא שהמספרים זהים לתוצאות הייחוס ב-README (ודאי 409 · סביר 493 · לבדיקה 850). אם לא – עצור ודווח.
6. הרץ גם `python run.py --fetch` כדי לוודא שההורדה מהאתר עובדת מהמחשב של רפי.
7. הצג לרפי מה עומד להיכנס ל-Git, ורק אחרי אישור שלו: commit + push. (push ל-main מפעיל deploy ב-Railway.)

## שלב 2 – מסך בדשבורד (לא להתחיל לפני שרפי מאשר)
מטרה: נושא חדש בתפריט, "השוואת מתחרים – סיגנט", במבנה של הדשבורדים הקיימים:
- דף העלאה לקובץ התוצאות (כמו דפי ההעלאה הקיימים, כולל שם הקובץ ותאריך העלאה אחרון ב-`file_uploads`).
- כרטיסי סיכום (ודאי / סביר / לבדיקה / ללא התאמה), סינון לפי מחלקה, רמת ביטחון וטקסט חופשי, טבלה ממוינת.
- לכל שורה: כפתורי **אישור / דחייה / תיקון מק"ט סיגנט**. ההחלטות נשמרות בטבלה נפרדת ולא נמחקות בהעלאה חדשה; בהצגה – החלטה ידנית גוברת על תוצאת המנוע.
- קישור לעמוד בקטלוג: `https://peledtech.com/catalog2024-25/<עמוד>/`.
- הרשאות דרך מערכת ה-topics הקיימת (`topics`, `user_topic_access`).

כללי עבודה מחייבים:
- **קודם תצוגה מקדימה ב-HTML של המסך, אישור מפורש מרפי, ורק אז קוד.** זה כלל קשיח.
- שינויי סכמה: עדכן את `schema.sql` **וגם** תן פקודות `CREATE TABLE` / `ALTER TABLE` מפורשות להרצה על מסד ה-PostgreSQL הקיים ב-Railway (`CREATE TABLE IF NOT EXISTS` לא מוסיף עמודות לטבלה קיימת).
- קרא את הקבצים בפועל מהדיסק לפני שינוי – אל תניח מה קיים.

## שלב 3 (בהמשך) – החלטות הבדיקה חוזרות למנוע
ייצוא ההחלטות מהדשבורד לקובץ `input/overrides.xlsx` (מק"ט ל.כ, מק"ט סיגנט, החלטה), ש-`build_all.py` יחיל בהרצה הבאה, כך שעבודת הבדיקה לא הולכת לאיבוד בהרצה מחדש.
